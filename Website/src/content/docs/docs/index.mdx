Caliper is a system monitor for the macOS menu bar. You build **widgets** — rows of numbers, graphs
and gauges — and each one becomes its own menu bar item, or sits on the desktop. They stay in the menu
bar's own colours until a reading crosses a line you set.

It **collects nothing and sends nothing about you**: everything it measures stays on your Mac, and
the only request it makes is a daily update check you can turn off. [Privacy](./privacy/) says
exactly what that request carries.

<Aside title="Why Caliper">
Named for the instrument: something precise you pick up, take a reading with, and put down again. The
app is meant to be glanced at and forgotten, and to speak up only when a number crosses a line you
set.
</Aside>

<CardGrid>
  <Card title="Build what you want to see" icon="pencil">

    processes behind it.
  </Card>
  <Card title="Share a widget" icon="document">
    Export one as a `.caliperwidget` file. Opening one previews it against your own Mac before
    anything reaches your menu bar.
  </Card>

## What it does not do

<Aside type="caution" title="Known limits">
Some of these are deliberate and some are walls in macOS. They are all written up in
[Known gaps](./known-gaps/) with the reason, so you can tell which is which before you file a bug.
</Aside>

- It is **not sandboxed**, and cannot be: temperatures, fans and power come from interfaces the App
  Store sandbox blocks. It is distributed as a signed, notarised download instead.
- It **never writes to the hardware**. The fan code can read the SMC and nothing else.
- It **does not use WidgetKit** for desktop widgets. WidgetKit cannot update every second.
- It **does not colour the menu bar for decoration**. Colour means a threshold was crossed.

## Conventions in these docs

Menu paths are written the way macOS writes them: *System Settings ▸ General ▸ Login Items*. Anything
in `monospace` is a literal — a metric id, a file, a command. A **metric id** like `cpu.usage.total`
is the name a reading has in widget files; [Sensors and metrics](./sensors/) lists them.
