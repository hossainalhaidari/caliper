## How Caliper was built

**Caliper's code was written with the help of AI.** Much of the Swift source, the tests, the build
scripts and this documentation was drafted with an AI coding assistant, then directed, reviewed and
shaped by a person.

**Testing the app itself was done by a human.** The automated test suite checks the logic, but how the
widgets actually look and behave — in the menu bar and on the desktop, with real sensors, in light and
dark, on real hardware — was tried by hand on a real Mac. The measurements on
[What it costs](../performance/) were taken the same way.

That is said here so you can weigh it for yourself. The full source is
[on GitHub](https://github.com/hossainalhaidari/caliper), and anything that looks wrong is welcome as
an [issue](https://github.com/hossainalhaidari/caliper/issues).
